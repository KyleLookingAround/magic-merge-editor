# magic-merge-editor

The active project lives in [`Personal PlanetPress program/template-editor/`](./Personal%20PlanetPress%20program/template-editor/) — see its `README.md` for build and dev instructions.

The original single-file source (`template-editor.html`) is being carved into ES modules under `template-editor/src/`. Migration plan and gotchas: [`Personal PlanetPress program/template-editor.handoff.md`](./Personal%20PlanetPress%20program/template-editor.handoff.md).
